## 真实代理探测

使用 B2Proxy 生成接口，固定参数：

```text
sessType=sticky&sessTime=180
```

### 提前更换 IP = 是

参数为 `sessAuto=1`。同一生成端口初始出口为 `38.3.186.20`，监测到第 `18.74` 分钟时出口变为 `149.102.85.166`。这说明供应商提前更换策略与 180 分钟目标冲突，不能用于长期维持同一打票出口。

### 提前更换 IP = 否

参数改为 `sessAuto=0` 后重新生成端口并持续监测。截至本记录生成时，同一生成端口 `128.14.147.102:17351` 的出口 `196.189.57.123` 已连续保持 `87.91` 分钟，未发生出口变化。第 `45.32` 分钟出现一次探测连接 EOF，随后恢复，不计为换 IP。

该结果验证了 180 分钟粘性 IP 必须使用 `sessTime=180&sessAuto=0`；`sessAuto=1` 不能作为固定出口方案。

### 292 票据

已实际取得多组 `292 + gpt-6-astra`，并在同一出口上按分钟重复请求。修正后的跟踪器记录到 6 个明确结束样本：

| 同一 292 持续 | 结束信号 |
| --- | --- |
| `6.05` 分钟 | `312 + gpt-5.6-luna` |
| `5.15` 分钟 | `312 + gpt-5.6-luna` |
| `5.00` 分钟 | `312 + gpt-5.6-luna` |
| `4.11` 分钟 | `312 + gpt-5.6-luna` |
| `1.13` 分钟 | `312 + gpt-5.6-luna` |
| `1.13` 分钟 | `312 + gpt-5.6-luna` |

这些样本的出口 IP 全程未变，说明结束点是上游 292 会话失效或路由变化，不是代理换 IP。另有较早样本持续 `3.4` 分钟后在 `4.6` 分钟内转为 `312`。

因此，`10` 分钟可能成功，但不能作为稳定下限；本轮实测最长连续样本为 `6.05` 分钟，且未证明单张 292 能持续 `180` 分钟。插件必须保留 312、模型不符和出口失效时的自动重采。

`sessTime=180` 是代理会话设置，不代表上游承诺 292 持续 180 分钟。插件仍会按本地 TTL、312、模型不符和出口失效事件重新采集。
