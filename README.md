# Sub2API STATE Kit 插件

本仓库维护 Sub2API `v0.2.8` 的独立 `.s2plugin` 插件，不覆盖宿主源码。`4.3.0` 在保留现有票据、Cookie 分流、代理生成器和备用票能力的基础上，增加 HostService v2 暂停账号过滤，以及请求日期、时区和语言统一。

## 最短配置

先选择“运行方式”，页面只要求填写当前方式需要的链路字段：

| 运行方式 | 适用场景 | 关键区别 |
| --- | --- | --- |
| 稳定同出口（推荐） | 已验证 180 分钟粘性 IP，要求打票和业务使用同一出口 | 同一个生成出口负责打票、复验和业务请求 |
| Cookie 分流 | 打票和业务必须使用不同出口 | 通过 `state + Cookie + session_id` 维持会话 |

第一层“IP 管理代理”两种方式共用，始终显示。它用于访问代理生成器 API；Cookie 分流的业务固定代理留空时，也作为业务出口。

## 请求环境统一

配置页新增“统一请求环境日期、时区与语言”开关，默认关闭。打开后：

- 请求里已经存在的 `<current_date>`、`<timezone>` 和 `user_location.timezone` 会按账号时区统一；
- 已经存在的 `Accept-Language` 会替换为 `en-US,en;q=0.9`；
- 默认时区为 `Asia/Singapore`，每个账号可以单独覆盖；
- 中国大陆、香港、澳门和台湾时区会被拒绝。

请求头或正文里原本没有这些字段时，插件不会凭空添加。

## 稳定同出口配置

1. 运行方式选择“稳定同出口”。
2. 第一层选择可访问生成器的代理。
3. 填写代理生成器 API。
4. 账号出口方式选择“代理生成器”。
5. 建议开启“优先使用上一轮出票 IP”和“提前准备备用票”。
6. 保存后等待状态变为“可用”，再用实际模型请求验收。

推荐参数：

| 参数 | 建议 |
| --- | --- |
| 禁止出口地区 | `HK` |
| 旧模式票据有效期 | `180` 分钟 |
| 旧模式提前续期 | `120` 秒起；打票不稳定时可调到 `300` 秒 |
| 备用票提前时间 | `90` 秒起，按实际续期耗时调整 |
| 常规重试间隔 | `10` 秒；地区被拦截或 312 会自动快速重试 |

## Cookie 分流配置

1. 运行方式选择“Cookie 分流”。
2. 第一层保持和稳定模式相同的选择。
3. 打票方式选择“代理生成器 API”或“S5/HTTP 固定采集代理”。
4. 选择代理生成器时，Cookie 采集代理留空。
5. 业务固定代理留空则使用第一层，也可以填写独立出口。
6. 保存后先用实际模型请求确认跨出口仍返回目标模型。

推荐参数：

| 参数 | 建议 |
| --- | --- |
| Cookie 票据持续期 | `300` 秒 |
| 备用票 | 开启 |
| 备用票提前时间 | `90` 秒 |
| 优先使用上一轮出票 IP | 开启 |

## 票据如何变为可用

插件不会把刚返回的 STATE 直接投入业务。一次成功获取必须依次完成：

1. 获取或复用生成出口，并检查出口地区。
2. 发起打票请求，确认 STATE 长度和实际模型。
3. 在业务出口上携带该 STATE 再复验一次。
4. 复验通过并保存成功后，才替换当前可用票据。

因此多出的是“同出口复验”，不是无效查票。续期或备用票获取期间，当前仍可用的旧票继续服务。

## 4.3.0 新增内容

- 同步官方 Sub2API `v0.2.8` 的 HostService v2 契约；
- 根据宿主返回的 `schedulable` 跳过暂停、限流、过载或额度不可调度的账号；
- 新增全局请求环境替换开关、默认时区和账号级时区；
- 保留 `v4.2.1` 的 Cookie 分流、备用票、生成器复用和地区过滤逻辑。

## 4.2.1 续期优化

- 将出口 IP 与地区检查合并为一次请求。
- 同一出口的复验只复核 IP 是否变化，不再重复查询地区。
- 地区被拦截、312、STATE 长度不符或复验失败时缩短重试等待。
- 旧模式也可提前准备备用票，优先复用当前正在工作的生成出口，失败后自动换新出口。
- 诊断耗时现在覆盖代理生成、出口检查和探测，便于继续调整提前量。

这些优化不降低复验标准，也不承诺固定获得 292。上游生命周期、出口质量和账号状态仍会决定最终成功率。

## B2Proxy 提取设置

注册入口：[B2Proxy](https://www.b2proxy.com/signup?code=FF10AB)

| 选项 | 设置 |
| --- | --- |
| 国家和地区 | `GLOBAL` |
| 提取数量 | `1` |
| 协议 | `HTTP/HTTPS` |
| 数据格式 | `TXT` |
| 会话类型 | `黏性IP` |
| IP 时长 | `180` 分钟 |
| 提前更换 IP | `否` |

生成器地址保留：

```text
proto=http&stype=txt&sessType=sticky&sessTime=180&sessAuto=0
```

不要使用 `sessAuto=1`。它可能在会话中途更换出口。

## 安装

下载对应架构的包：

```text
sub2api-state-kit_plugin_v4.3.0_linux-amd64.s2plugin
```

首次安装先把 Release 中的 `trusted-publisher.yaml` 合并到宿主现有 `config.yaml`，重启一次 Sub2API，再上传同架构 `.s2plugin`。已安装旧版时可以直接升级，配置会保留。

完整说明见 [插件安装与使用指南](docs/plugin.md)，探测和验证边界见 [插件验证记录](docs/plugin-validation.md)。
